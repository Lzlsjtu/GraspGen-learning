## 📐 数学原理

### 针孔相机投影模型
从像素坐标 `(u, v)` 到 3D 空间坐标 `(X, Y, Z)`:

```
X = (u - cx) * d / fx
Y = (v - cy) * d / fy
Z = d
```

其中:
- `d`: 深度值（米）
- `fx, fy`: x, y 方向焦距
- `cx, cy`: 主点坐标（光心）

### GraspGen 6-DOF 抓取表示
```
抓取位姿 = [位置(3) + 旋转(3)] ∈ SE(3)
grasp_repr = "r3_so3"  # 轴角表示 (Lie Algebra)
```

### 训练损失函数
```
Loss = λ_pos * L1_loss(position) + λ_rot * L1_loss(rotation)
λ_pos = 1.0, λ_rot = 1.0
```
