# 基于局部点云的6自由度抓取位姿估计 - 课程项目介绍
---
## 📚 课程信息
- **课程名称**：机器人视觉与抓取
- **项目题目**：题目三 - 基于局部点云的6自由度抓取位姿估计
- **交付成果**：完整可运行代码、答辩PPT、训练结果、演示视频
---
## 🎯 项目目标
基于NVIDIA GraspGen扩散模型，实现从RGB-D图像到6-DOF抓取位姿的完整Pipeline，满足：
1. ✅ 输入：RGB-D图像（RealSense D435 1280×720分辨率）
2. ✅ 输出：物体上的最优抓取位姿（旋转+平移，共6自由度）
3. ✅ 功能：点云预处理、抓取生成、碰撞检测、可视化
4. ✅ 性能：在RTX 3060笔记本上推理速度<0.2s/帧
