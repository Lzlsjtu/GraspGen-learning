### 3.3 生成 UUID → 网格映射文件

我们的物体数据集是完整 Objaverse 的子集（475/8515），需要生成映射文件和过滤后的 split：

```bash
cd /home/lzl/Projects/6Dpose/GraspGen
source .venv/bin/activate

python -c "
import json, os, random

# 生成 map_uuid_to_path.json
obj_dir = '/home/lzl/Projects/6Dpose/GraspGen_datasets/object_dataset'
glb_files = [f for f in os.listdir(obj_dir) if f.endswith('.glb')]
mapping = {f.replace('.glb', ''): f for f in glb_files}
with open(os.path.join(obj_dir, 'map_uuid_to_path.json'), 'w') as f:
    json.dump(mapping, f, indent=2)
print(f'Mapped {len(mapping)} objects')

# 计算 overlap 并创建 subset splits
with open(os.path.join(obj_dir, 'map_uuid_to_path.json')) as f:
    mesh_uuids = set(json.load(f).keys())
with open(f'{obj_dir}/../grasp_data/grasp_data/franka_panda/uuid_index.json') as f:
    grasp_uuids = set(json.load(f).keys())

valid_uuids = sorted(grasp_uuids & mesh_uuids)
random.seed(42); random.shuffle(valid_uuids)
split = int(0.8 * len(valid_uuids))

# 写入 filtered splits
split_dir = f'{obj_dir}/../grasp_data/splits/franka_panda_subset'
os.makedirs(split_dir, exist_ok=True)
for name, uuids in [('train', valid_uuids[:split]), ('valid', valid_uuids[split:])]:
    with open(os.path.join(split_dir, f'{name}.txt'), 'w') as f:
        f.write('\n'.join(uuids))
    print(f'{name}: {len(uuids)} objects')
"
```

## 4. 启动训练

### 4.1 训练命令

```bash
cd /home/lzl/Projects/6Dpose/GraspGen
source .venv/bin/activate

    train.debug=True \

    data.gripper_name="franka_panda" \
    data.num_points=1024 \
    data.num_grasps_per_object=100 \
    data.prob_point_cloud=0.0 \
    data.redundancy=1 \
    data.dataset_name="objaverse" \
    data.dataset_version="v2" \
    data.dataset_cls="ObjectPickDataset" \
    data.cache_dir="/home/lzl/Projects/6Dpose/graspgen_source/runs/results_assignment/cache" \
    data.rotation_augmentation=True \
    data.load_contact=False \
    data.visualize_batch=False \

    train.batch_size=2 \
    train.num_epochs=200 \
    train.num_workers=0 \

    train.save_freq=40 \
    train.eval_freq=40 \
    train.model_name="diffusion" \
    train.checkpoint="" \
    diffusion.gripper_name="franka_panda" \
    diffusion.num_diffusion_iters=10 \
    diffusion.num_diffusion_iters_eval=10 \
    diffusion.obs_backbone="pointnet" \

    diffusion.compositional_schedular=True \
```

### 4.2 关键参数说明

| 参数 | 值 | 说明 |
|------|----|------|
| `train.debug=True` | 单进程运行 | 避免 DDP 多进程，适配单 GPU |
| `data.num_points=1024` | 点云点数 | RTX 3060 6GB 限制，完整训练用 16384 |
| `train.batch_size=2` | 批次大小 | 6GB 显存限制，完整训练用 8 |
| `train.num_workers=0` | 数据加载线程 | 设为 0 避免多进程内存开销 |
| `diffusion.obs_backbone=pointnet` | 特征编码器 | pointnet 最省显存（~2GB），ptv3 需 ~5GB |
| `diffusion.num_diffusion_iters=10` | 扩散步数 | 步数越多精度越高但训练越慢 |
| `data.prob_point_cloud=0.0` | 部分点云概率 | 设为 0 使用 mesh 表面采样（无需 pyrender/OSMesa） |
| `data.num_grasps_per_object=100` | 每物体抓取数 | 完整数据集用 500+ |
| `train.eval_freq=40` | 验证频率 | 每 40 epoch 验证一次 |
| `train.save_freq=40` | 保存频率 | 每 40 epoch 保存 checkpoint |

## 7. 合盖不中断训练

合上笔记本盖子默认会触发系统休眠（suspend），导致训练中断。以下是几种防止方法：

### 方法 1：systemd-inhibit（推荐，临时生效）

```bash
# 阻止合盖休眠，直到 Ctrl+C 终止
systemd-inhibit \
    --what=handle-lid-switch:sleep:idle \
    --why="GraspGen training in progress" \
    --mode=block \
    sleep 86400
```

`sleep 86400` 会持续 24 小时。按 `Ctrl+C` 恢复正常。

### 方法 2：修改 logind.conf（永久生效）

```bash
sudo nano /etc/systemd/logind.conf
# 修改以下行：
# HandleLidSwitch=ignore
# HandleLidSwitchExternalPower=ignore
# 保存后重启服务：
sudo systemctl restart systemd-logind
```

### 方法 3：tmux/screen + nohup（远程 SSH 场景）

```bash
# 在 tmux 中启动训练，即使 SSH 断开也不会中断
tmux new -s training
bash runs/train_assignment_gen.sh
# Ctrl+B D 分离会话
# 重新连接: tmux attach -t training
```

## 8. 已知问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| `map_uuid_to_path.json not found` | 物体数据集未生成映射文件 | 运行 §3.3 的 Python 脚本 |
| `FileNotFoundError: map_uuid_to_path.json` | 同上 | 同上 |
| `pyrender: Rendering is not available` | 无 OSMesa/显示环境 | 设 `data.prob_point_cloud=0.0` 使用 mesh 采样 |
| `meshcat.TriangularMeshGeometry` 不存在 | meshcat 0.0.12+ API 变更 | 已修复（`grasp_gen/utils/meshcat_utils.py`） |
| PTV3 backbone 训练 OOM | 6GB 显存不足 | 使用 `pointnet` backbone |
| 训练脚本被 kill 无错误信息 | CPU/内存不足 | 降低 `num_workers=0`，`batch_size=2` |
