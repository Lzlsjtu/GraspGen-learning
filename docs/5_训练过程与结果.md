## 2. 训练数据流

### 2.1 输入

```
物体网格 (.glb)  +  抓取标注 (.json, WebDataset)
         │
         ▼
  ┌─────────────────────────┐
  │ 采样物体表面点云          │  trimesh.sample.surface()
  │ N_points = 1024          │  → (1024, 3) 物体局部点云
  └──────────┬──────────────┘
             │
  ┌──────────▼──────────────┐
  │ 中心化 & 缩放             │  p' = κ · (p - mean_pos)
  │ κ = 3.27                │  → 数值范围约 [-1, 1]
  └──────────┬──────────────┘
             │
  ┌──────────▼──────────────┐
  │ 抓取位姿 → RT 编码        │  matrix_to_rt()
  │ grasp_repr = r3_so3     │  → [tx,ty,tz, ωx/π,ωy/π,ωz/π]
  │                          │     (6 维向量，范围 [-1,1])
  └──────────┬──────────────┘
             │
             ▼
    模型输入:  { "points": (B, 1024, 3)  }
    监督信号:  { "grasps": (B, K, 4, 4)  }
```

**数据规模**：
| 属性 | 值 |
|------|-----|
| 训练物体数 | 380（franka_panda_subset） |
| 验证物体数 | 95 |
| 每物体抓取数 | 100（正样本 + 负样本混合） |
| 完整数据集 | 7657 物体（我们用了子集） |
| 点云类型 | 完整点云（`prob_point_cloud=0.0`，mesh 表面采样） |

### 2.2 输出

```
模型输出 (B, K, 6)          →  rt_to_matrix()  →  (B, K, 4, 4)
[tx, ty, tz, ωx, ωy, ωz]     so(3) Exp Map       齐次抓取位姿矩阵
```

每个批次输出 K=100 个候选抓取位姿（4×4 齐次矩阵），表示夹爪基座坐标系相对于物体坐标系的刚体变换。

**输出解读**：
- 平移分量 `(tx, ty, tz)`：夹爪 TCP（工具中心点）在物体坐标系中的位置
- 旋转分量 `(ωx, ωy, ωz)`：轴角表示 × (1/π)，通过 `so3_exp_map(ω·π)` 恢复旋转矩阵
- 第 4 行恒为 `[0, 0, 0, 1]`

## 3. Loss 配置详解

### 3.1 扩散模型核心损失

GraspGen Generator 使用 DDPM 扩散模型，核心训练目标是**噪声预测**：

\[
\mathcal{L}_{\text{diff}} = \mathbb{E}_{t, g_0, \varepsilon}\left[\|\varepsilon - \varepsilon_\theta(\sqrt{\bar{\alpha}_t} g_0 + \sqrt{1-\bar{\alpha}_t}\varepsilon, t, pc)\|^2\right]
\]

其中：
- \(t \sim \text{Uniform}(0, T-1)\)，\(T = 10\)（扩散步数）
- \(\varepsilon \sim \mathcal{N}(0, \mathbf{I})\)（标准高斯噪声）
- \(pc\) 是物体点云（条件信号）
- \(\varepsilon_\theta\) 是噪声预测网络（DiffusionNoisePredictionNet）

### 3.2 实际配置的损失项

```yaml
diffusion:
  loss_pointmatching: false    # 抓取点匹配 Chamfer 损失（已关闭）
  loss_l1_pos: true            # 平移分量 L1 损失
  loss_l1_rot: true            # 旋转分量 L1 损失
  compositional_schedular: true # 平移/旋转分离噪声调度
```

| 损失项 | 权重 | 公式 | 说明 |
|--------|------|------|------|
| `noise_pred` (position_loss) | 1.0 | \(\|\varepsilon_{pos} - \hat{\varepsilon}_{pos}\|_1\) | 平移噪声预测 L1 |
| `noise_pred` (rotation_loss) | 1.0 | \(\|\varepsilon_{rot} - \hat{\varepsilon}_{rot}\|_1\) | 旋转噪声预测 L1 |

**总损失**：

\[
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{position}} + \mathcal{L}_{\text{rotation}}
\]

（`loss_pointmatching=false` 所以 Chamfer 损失未启用）

### 3.3 组合噪声调度器

```yaml
diffusion:
  num_diffusion_iters: 10       # T = 10 扩散步
  compositional_schedular: true # 平移/旋转独立调度
```

- **平移**：`scaled_linear` beta schedule — 线性噪声增长
- **旋转**：`squaredcos_cap_v2` beta schedule — 余弦噪声调度

两种调度分开是因为平移空间（\(\mathbb{R}^3\)，欧几里得）与旋转空间（\(SO(3)\)，非欧几里得）的几何性质不同。

### 3.4 旋转表示

```yaml
diffusion:
  grasp_repr: r3_so3   # so(3) 李代数轴角表示
  kappa: 3.27           # 点云缩放因子
```

**编码**（`SO(3) → ℝ³`）：
\[
\omega = \text{Log}(R) = \frac{\theta}{2\sin\theta}(R - R^T)^\vee, \quad g_{\text{enc}} = \frac{\omega}{\pi} \in [-1, 1]^3
\]

**解码**（`ℝ³ → SO(3)`）：
\[
R = \exp(\pi \cdot g_{\text{enc}}^\wedge) = I + \frac{\sin\theta}{\theta}(\pi g_{\text{enc}})^\wedge + \frac{1-\cos\theta}{\theta^2}(\pi g_{\text{enc}}^\wedge)^2
\]

### 3.5 验证评估指标

验证时不计算噪声预测损失，而是执行完整的去噪过程（10 步 DDPM 逆向采样）得到重建抓取，然后与 ground truth 对比：

| 指标 | TensorBoard Tag | 目标 |
|------|----------------|------|
| 平移 L2 误差 | `valid/metric/reconstruction/error_trans_l2` | < 5 cm |
| 旋转测地线误差 | `valid/metric/reconstruction/error_rot_geodesic` | < 0.3 rad (~17°) |
| Recall | `valid/metric/reconstruction/recall` | GT 抓取中被预测覆盖的比例 |
| Precision | `valid/metric/reconstruction/precision` | 预测抓取中匹配到 GT 的比例 |

## 4. Epoch 数量建议

### 4.1 论文参考

GraspGen 论文使用 **8×A100** 训练 **3000 epoch**（Generator ~40h，Discriminator ~90h）。

### 4.2 我们的情况

| 对比维度 | 论文 | 我们 |
|----------|------|------|
| GPU | 8× A100 (80GB) | 1× RTX 3060 (6GB) |
| 数据集 | 7657 物体 | 380 物体（4.9%） |
| 每物体抓取 | 500+ | 100 |
| 点云点数 | 3500+ | 1024 |
| Batch size | 64 (8×8) | 2 |
| Backbone | PTV3 | PointNet（最简） |
| Diffusion steps | 10 | 10 |

### 4.3 验证曲线分析

| Epoch | 平移误差 | 改善速率 |
|-------|----------|----------|
| 1 → 40 | 0.327 → 0.197 | -0.0033 m/epoch |
| 40 → 80 | 0.197 → 0.160 | -0.0009 m/epoch |
| 80 → 120 | 0.160 → 0.127 | -0.0008 m/epoch |
| 120 → 160 | 0.127 → 0.110 | -0.0004 m/epoch |

**改善速率在减慢**（学习率衰减的预期行为），但所有指标仍在单调改善中，**200 epoch 远未收敛**。

### 4.4 推荐

以平移误差 < 5cm 为目标，线性外推约需 **400-500 epoch**。考虑到改善速率衰减，建议：

> **训练至 500 epoch**（当前已完成 163，还需 337 epoch，RTX 3060 约需 8-10 小时）

这样可以在报告中展示从初始到收敛的完整验证曲线，更有说服力。

## 5. GraspNet-1Billion RGB-D 推理管线计划

### 5.1 目标

使用 GraspNet-1Billion 数据集提供的 **RGB-D 图像**，经过相机内参转换生成点云，输入训练好的 GraspGen 模型，验证抓取位姿预测效果。

### 5.2 流程

```
GraspNet-1Billion 数据
   │
   ├── RGB 图像 (H×W×3)
   ├── Depth 图像 (H×W×1)
   └── 相机内参 (fx, fy, cx, cy)
          │
          ▼
   ┌──────────────────────┐
   │ ① RGB-D → 点云        │  depth2points()
   │ d·[(u-cx)/fx,        │  或 GraspNet 内置 API
   │    (v-cy)/fy, 1]     │
   └──────────┬───────────┘
              │ (N, 3) 场景点云
              ▼
   ┌──────────────────────┐
   │ ② 实例分割 → 物体点云  │  SAM2 或 GraspNet mask
   │ 提取目标物体区域        │
   └──────────┬───────────┘
              │ (M, 3) 物体局部点云
              ▼
   ┌──────────────────────┐
   │ ③ 点云预处理           │  SOR 离群点剔除
   │ + FPS 降采样 → 1024  │  中心化 + 缩放 (κ=3.27)
   └──────────┬───────────┘
              │ (1024, 3) 标准输入
              ▼
   ┌──────────────────────┐
   │ ④ GraspGen 推理       │  GraspGenSampler
   │ 10 步 DDPM 去噪       │  输出: 100 个抓取位姿
   └──────────┬───────────┘
              │ (100, 4, 4) 候选抓取
              ▼
   ┌──────────────────────┐
   │ ⑤ 碰撞检测 + 排序     │  filter_colliding_grasps()
   │ 过滤不可行抓取         │  按 confidence 降序
   └──────────┬───────────┘
              │
              ▼
   ┌──────────────────────┐
   │ ⑥ Open3D 可视化       │  点云 + 夹爪网格 + 抓取位姿
   │ + 定量评估            │  recall / precision / 碰撞率
   └──────────────────────┘
```
